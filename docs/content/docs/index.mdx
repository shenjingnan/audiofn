**AudioFn** 是一个开源的本地优先桌面 ASR & TTS 工具（An open-source, local-first desktop
ASR & TTS toolkit with voice cloning）：离线语音转写 + 音色克隆，推理由 audio.cpp 引擎
（ggml）在本机完成，音频与文本数据不出设备。

提供 **Tauri 2 桌面面板**（概览 / 模型 / 转写 / 合成 / 音色库 / 设置）与 **`audiofn` 命令行**
两种形态，能力一致、配置共享（`~/.audiofn/settings.toml`）。

## 特性

- **语音识别（ASR）** — Qwen3-ASR-0.6B 离线转写，30 语言自动识别；文件转写与录音听写两种入口
- **语音合成（TTS）** — Qwen3-TTS-0.6B / 1.7B 零样本音色克隆：5–30 秒参考音频 + 对应文本，
  即可用该音色合成任意文本（中英日韩等 10 语种）
- **模型库** — 应用内一键下载、sha256 校验、切换当前模型；模型本体不入库
- **本地优先** — 模型与推理全部在本地，无账号、无上传、无遥测
- **跨平台** — macOS 13+（Apple Silicon / Intel）与 Linux x86_64；不提供 Windows 版本

## 平台与引擎

| 平台 | 引擎后端 | 安装包 |
| ---- | -------- | ------ |
| macOS 13+ (Apple Silicon) | Metal（GPU） | `.dmg` |
| macOS 13+ (Intel) | CPU | `.dmg` |
| Linux x86_64 | CPU | `.deb` / `.rpm` / `.AppImage` |

模型不随安装包分发：首次使用在应用「模型」页一键下载（ASR 约 1.1GB，TTS 约 1.9GB 起），
详见[模型库](/docs/models)。
