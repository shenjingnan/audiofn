# 桌面端

桌面应用基于 Tauri 2，复用 CLI 的同一套 ASR / TTS / 模型库 / 配置逻辑，与 CLI 共享
`~/.audiofn/` 下的模型、音色库与设置。

## 安装

从 [README「应用下载」](https://github.com/shenjingnan/audiofn#应用下载)选择对应平台的安装包：

| 系统 | 包 |
| ---- | -- |
| macOS 13+ (Apple Silicon / Intel) | `.dmg` |
| Linux x86_64 | `.deb` / `.rpm` / `.AppImage` |

安装后首次使用，到「模型」页下载 ASR / TTS 模型即可开始。

> **macOS 未签名提示**：首次打开若提示「"AudioFn" 已损坏，无法打开」，并非真的损坏
> （应用未做 Apple 签名公证，被 Gatekeeper 拦截）。双击 dmg 窗口里的
> **首次打开修复.command**，自动安装到「应用程序」、清除隔离属性并启动；
> 或手动执行 `xattr -cr /Applications/AudioFn.app`。

## 页面导览

| 页面 | 功能 |
| ---- | ---- |
| **概览** | ASR / TTS 当前模型、设备与系统资源状态 |
| **模型** | 模型库：一键下载、sha256 校验、切换当前模型；含 ASR（转写）与 TTS（合成）两个子页 |
| **转写（ASR）** | 文件转写与免提听写（录音 → 停止后整段出文本） |
| **合成（TTS）** | 文本合成 + 音色管理（上传音频或在线录音克隆音色） |
| **设置** | 麦克风设备、存储位置、快捷键、数据目录、日志与重启 |

## audio.cpp 引擎

推理由 audio.cpp 引擎（`audiocpp_server`）以 sidecar 子进程完成，二进制随安装包分发，
无需单独安装。macOS（Apple Silicon）走 Metal 加速，Linux 纯 CPU。

自行编译开发版请看 [CONTRIBUTING「audio.cpp sidecar 引擎」](https://github.com/shenjingnan/audiofn/blob/main/CONTRIBUTING.md#audiocpp-sidecar-引擎)。
