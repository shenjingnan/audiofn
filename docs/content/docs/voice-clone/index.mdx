# 音色克隆指南

Qwen3-TTS 是零样本音色克隆模型：给一段**参考音频**和它的**逐字转写文本**，
模型就能用同一个音色合成任意文本（中英日韩德法俄葡西意 10 语种）。

## 三步克隆

1. **录参考音频**：5–30 秒、环境安静、语速自然的一段录音（wav / 16kHz 以上更佳）
2. **写参考文本**：逐字写下音频里说的内容，不能多字、少字或改写
3. **合成**：

```bash
audiofn tts run --text "要合成的任意文本" \
  --reference-wav ref.wav \
  --reference-text "参考音频里说的原话" \
  --output out.wav
```

## 用音色库复用音色

在桌面端「模型 → 语音合成 → 音色管理」里：

- **上传音频**：选择本地 wav，填写音色名称与参考文本（可点「自动转写」）
- **在线录音**：选 3 / 5 / 10 秒时长，录音后同样填写名称与参考文本

保存后进入 `~/.audiofn/voices/`（wav + `manifest.json`），桌面端与 CLI 都能复用：

```bash
audiofn tts voices                        # 查看音色 id
audiofn tts run --text "你好" --voice <音色id>
```

## 参考音频质量建议

| 因素 | 建议 |
| ---- | ---- |
| 时长 | 5–30 秒；太短音色不稳定，太长不提升效果还更慢 |
| 环境 | 安静、无混响、无背景音乐 |
| 说话 | 自然语速、情绪平稳；避免念稿式的生硬停顿 |
| 文本 | 参考文本必须逐字一致，标点可省略但字不能错 |
| 权限 | 只克隆你有权使用的声音，尊重他人权益与当地法律 |

## 常见问题

- **合成报错要求提供参考音色**：Base 版模型没有「自动音色」兜底，必须传
  `--voice` 或 `--reference-wav` + `--reference-text`
- **音色不像**：优先检查参考文本是否逐字一致、录音是否安静；换一段更长的干净录音
- **合成很慢**：TTS 为整段非流式合成，耗时随文本长度线性增长；macOS 可确认
  `provider` 走 Metal，Linux 为纯 CPU
