# CLI

`audiofn` 命令行与桌面面板能力一致：`asr` 语音转写、`tts` 语音合成、`config` 查看配置。
Shell 补全支持 bash / zsh / fish / powershell / elvish（`audiofn completion <shell>`，
隐藏命令，不出现在 `--help` 列表）。

从源码运行时用 `cargo run -- <命令>` 代替 `audiofn <命令>`。

## 快速开始

```bash
# 下载模型（默认安装到 ~/.audiofn/models/，不入库）
audiofn asr install-model
audiofn tts install-model

# 转写
audiofn asr transcribe --wav rec.wav

# 克隆合成
audiofn tts run --text "你好" \
  --reference-wav ref.wav --reference-text "参考音频里说的原话" --output out.wav
```

## ASR

Qwen3-ASR-0.6B 离线转写：30 语言自动识别，原生输出标点，不支持热词。

```bash
audiofn asr transcribe --wav rec.wav        # 文件转写（--language zh 可指定语种）
audiofn asr dictate                          # 麦克风录音，回车 / Ctrl-C 停止后整段转写
audiofn asr devices                          # 列出输入设备
audiofn asr install-model                    # 下载模型（--registry-id / --force）
```

| 命令 | 说明 |
| ---- | ---- |
| `asr transcribe` | 离线转写 wav。`--wav`（缺省用模型自带示例音频）、`--language`、`--model-dir` |
| `asr dictate` | 录音 → 停止 → 整段转写。`--device`、`--duration`、`--language`、`--model-dir` |
| `asr devices` | 列出可用输入设备 |
| `asr install-model` | 安装 ASR 模型（缺省 `asr-qwen3-0.6b-audiocpp`） |

## TTS

Qwen3-TTS-0.6B / 1.7B 零样本音色克隆（10 语种）。Base 版无内置音色兜底，
**必须提供参考音色**（`--voice` 或 `--reference-wav` + `--reference-text`）。

```bash
audiofn tts run --text "你好" \
  --reference-wav ref.wav --reference-text "参考音频里说的原话" --output out.wav
audiofn tts run --text "你好" --voice my-voice --speed 1.1
audiofn tts voices                           # 音色库：模型包内置 + 自定义音色
audiofn tts install-model                    # 下载模型（缺省 0.6B，--registry-id 切 1.7B）
```

| 命令 | 说明 |
| ---- | ---- |
| `tts run` | 合成文本为 wav。`--text` 必填；`--reference-wav/--reference-text`、`--voice`、`--speed`、`--output`、`--model-dir`、`--engine-path` |
| `tts voices` | 列出可用音色 |
| `tts install-model` | 安装 TTS 模型（缺省 `tts-qwen3-06b-base-q8-audiocpp`） |

## 配置

配置文件：`~/.audiofn/settings.toml`（TOML，支持 `${env.VAR}` 环境变量引用），桌面端与
CLI 共用。常用段：

```toml
[asr]
model_dir = "/path/to/model"   # 模型目录
language = "zh"                # 语种；缺省自动识别
provider = "cpu"               # auto 时 macOS 用 Metal，Linux 纯 CPU
num_threads = 2

[tts]
model_dir = "/path/to/model"
model_type = "qwen3_tts_06"    # qwen3_tts_06 | qwen3_tts_17
backend = "audiocpp"
voice = "my-voice"             # 默认音色（音色库 id）
speed = 1.0

[model_library]
local_models = []              # 手动注册的本地模型

[shortcuts]                    # 桌面端全局快捷键
```

数据目录：`~/.audiofn/`（`settings.toml`、`models/`、`voices/`、`tts/` 合成输出、日志），
可用 `data_dir` 把模型等大文件挪到别的盘。

## 退出码与排错

- 模型未安装 → 命令输出会给出对应的 `install-model` 提示
- 引擎未找到 → 用 `--engine-path` 显式指定 `audiocpp_server`，或放入 `~/.audiofn/engines/`
- 听写无声音 → 先 `audiofn asr devices` 确认设备名，再用 `--device` 指定
