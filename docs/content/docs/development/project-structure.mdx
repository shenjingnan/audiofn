# 项目结构

```
├── Cargo.toml           # workspace 根（crate：audiofn，CLI bin：audiofn-cli）
├── rust-toolchain.toml  # Rust 工具链版本（1.97.1）
├── src/
│   ├── main.rs          # 入口文件
│   ├── lib.rs           # 库入口 + 测试工具（test_util 临时 HOME 隔离）
│   ├── cli.rs           # CLI 命令定义（asr / tts / config / completion）
│   ├── asr/             # 语音识别（offline 文件转写 + dictate 听写）
│   ├── tts/             # 语音合成（合成 + 音色解析 + 自定义音色库）
│   ├── audiocpp/        # audio.cpp sidecar 客户端（定位 / 生命周期 / SSE / 模型族表）
│   ├── model_library/   # 模型库（registry 预设 / 下载校验 / 安装 / 扫描）
│   ├── audio.rs         # cpal 麦克风采集 + 重采样
│   ├── config/          # settings.toml 配置 + shortcuts
│   ├── logging.rs       # tracing 双层日志（文件 + stderr）
│   └── datetime.rs      # 日期时间工具
├── models/              # 模型清单（本体不入库，按清单下载）
│   ├── manifest.json    # 资产清单（source / sha256 / license / 文件名）
│   ├── model_registry.json # 模型库预设
│   ├── verified_registry.json # 人工验证记录
│   └── THIRD_PARTY_NOTICES.md
├── src-tauri/           # Tauri 2 桌面应用（workspace 成员）
│   ├── src/lib.rs       # Tauri commands + 听写 / 合成线程
│   ├── frontend/        # React + Vite + TypeScript 控制面板（Tailwind + shadcn/ui）
│   ├── tauri.conf.json  # Tauri 配置（打包 / externalBin / 权限文案）
│   ├── capabilities/    # 权限声明
│   └── icons/           # 应用图标
├── docs/                # fumadocs 文档站（Next.js + MDX）
│   ├── content/docs/    # 文档内容
│   ├── app/             # 页面与布局
│   └── lib/             # 内容源 loader 与平台检测
├── tests/               # 集成测试
├── package.json         # Tauri CLI（@tauri-apps/cli）
├── scripts/             # 引擎获取 / dmg 修复注入 / 图标生成等脚本
├── .github/             # CI / 发布 / 网盘上传流水线
└── .githooks/           # Git hooks
```

## 关键模块说明

| 模块 | 职责 |
| ---- | ---- |
| `src/asr/` | Qwen3-ASR 转写入口：`offline.rs`（wav 文件）、`dictate.rs`（麦克风录音 → 停止后整段转写） |
| `src/tts/` | Qwen3-TTS 合成入口：`voice.rs` 解析音色参数，`voice_store.rs` 管理自定义音色库 |
| `src/audiocpp/` | audio.cpp 引擎 sidecar：`locator.rs` 定位二进制、`server.rs` 管理子进程、`client.rs` SSE 流式请求 |
| `src/model_library/` | 模型库：预设过滤、流式下载、sha256 校验、原子落位与已安装扫描 |
| `src/audio.rs` | cpal 采集、设备枚举、采样率重采样（→ 16k mono） |
| `src-tauri/` | 桌面面板：Tauri commands + 听写/合成线程，前端 React 页面（概览 / 模型 / 设置） |

用户数据目录：`~/.audiofn/`（`settings.toml`、`models/`、`voices/`、`tts/` 合成输出、日志）。
