# 依赖说明

| 分类 | Crate | 用途 |
|------|-------|------|
| 核心 | clap / clap_complete | CLI 参数解析 / Shell 补全生成 |
| 核心 | tokio | 异步运行时 |
| 核心 | serde / serde_json / toml | 序列化 |
| 核心 | chrono | 日期时间处理 |
| 核心 | tracing / tracing-subscriber | 日志 |
| 核心 | thiserror / anyhow | 错误处理 |
| 音频 | cpal | 麦克风采集与设备枚举 |
| 音频 | hound | wav 解码 / 编码（sidecar 返回的 wav → f32 样本、听写落盘） |
| 音频 | objc2 / block2 / objc2-av-foundation | macOS 麦克风权限请求（仅 macOS target 编译） |
| 引擎 | reqwest | audio.cpp sidecar HTTP/SSE 客户端（blocking + multipart） |
| 引擎 | base64 | sidecar SSE 流式 delta 载荷解码 |
| 引擎 | sysinfo | sidecar 残留进程按 pid 检查与清理 |
| 模型下载 | ureq | 流式下载（socks 代理 + 系统证书存储校验 TLS） |
| 模型下载 | sha2 / hex | 下载模型的 sha256 校验 |
| 测试 | tempfile | 临时 HOME 隔离（test_util） |
| 测试 | tiny_http | audiocpp client 单测的 stub SSE server |

ASR / TTS 推理不在 Rust 进程内完成：引擎是独立的 `audiocpp_server` sidecar
（audio.cpp，ggml），Rust 侧只负责进程生命周期与 SSE 协议，因此没有 onnx / llama
类的原生绑定依赖。
